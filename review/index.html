What the service does

Choosing Start Host runs the game engine and local WebSocket server on the host phone. Other devices on the same trusted network exchange game actions and state with that host. The foreground service keeps this ongoing, user-started connection available when the app is backgrounded.

User controls

  • The user starts hosting from Host Local Game.
  • An ongoing notification identifies the active host. Tapping it returns to the hosted game.
  • Stop hosting in the notification ends the service and local connections.
  • Stop Hosting is also available from the in-game Game menu and LAN drawer.

LAN requires the optional Full unlock. This demonstration uses the Full testing build. The public app exposes the same LAN controls after Full is unlocked.
